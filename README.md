![LVTT Logo](images/logo.png)

> **機密情報を扱える、完全プライベートなAIマルチエージェント会議室**  
> 外部クラウドへの送信ゼロ・Ollamaローカル推論による安全なアイデア発散と意思決定支援システム。

---

## ✦ Local Virtual ThinkTank とは？

Local Virtual ThinkTank (LVTT) は、未公開の新規事業企画、特許・知財戦略、社外秘メモ、ソースコードなどの機密情報を安全にブレインストーミングするための、**完全オンプレミス型AIマルチエージェント意思決定支援システム**です。

鳥の子色（#FAF9F6）と素色、深墨を基調とした上質な**「禅（Zen）デザインシステム」**を採用し、深い思索と集中を促す静謐なUI/UXを提供します。

---

## ✦ 3つのコアバリュー

| コアバリュー | 特徴 | 価値 |
| :--- | :--- | :--- |
| **🔒 外部クラウド送信ゼロ (100% Local)** | 社内閉域網・オンプレミスインフラ内のローカルLLMのみで完結。 | 未公開特許、社外秘データ、独自ソースコードも漏洩リスクなく投入可能。 |
| **🎭 専門AIによる多角的壁打ち** | 助走モードでテーマに応じた専門エージェントをAIプロデューサーが自動編成。 | 視点の偏りを解消し、賛成・反対・論理分析など多面的な議論を展開。 |
| **👤 人間介入（HITL）と自律の調和** | 自動議論を眺めるだけでなく、任意のタイミングで「人間コメント」を差し込み可能。 | 議論が脱線した際の軌道修正や、停滞時のファシリテーター介入を自在にコントロール。 |

## ✦ 主要機能

1. **助走モード（会議準備・プロデュース）**
   - テーマと前提情報を入力するだけで、プロデューサーAIが最適なエージェント編成、議論モード（ディベート・合意形成・アイデア発散等）、ラウンド数を自動提案。
2. **2ペイン構成のリアルタイム会議室**
   - 左ペインでエージェント同士の活発な発言タイムラインを閲覧。右ペインで議論サマリーや主要論点、アクションアイテムをリアルタイム整理。
3. **動的ラウンド制御 & 停滞検知**
   - ラウンドの延長・早期収束をボタン1つで操作可能。議論がループした際は停滞を自動検知し、エスカレーションを促します。
4. **構造化議事録 & セキュアエクスポート**
   - 会議終了後、要約・論点・ToDoを含む構造化議事録を自動生成。Markdown形式（.md）およびJSON形式での即時ダウンロードに対応。
5. **議論リレー（フェーズ引き継ぎ）**
   - 前回の会議の結論や未解決課題を引き継ぎ、次のステップの会議をスムーズに連続開催。
6. **会議履歴・過去ログ管理**
   - 過去の全議論をローカルにセキュア保存。キーワード検索やフィルタリングでいつでも過去の知見を再利用可能。
7. **「禅（Zen）」ライトモード ⇄ 「漆（Urushi）」ダークモード**
   - 伝統的な美意識とモダンWeb設計を融合したワンタップのテーマ切り替え。
